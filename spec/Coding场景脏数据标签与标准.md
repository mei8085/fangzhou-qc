## 脏数据标签组合规则

- L1 粒度要打的脏数据标签：`反馈质量脏数据标签 + 平台 & 模型表现 + Harness 表现`
- L2 粒度要打的脏数据标签：`题目质量脏数据标签 + L2 粒度的反馈质量脏数据标签`

## 飞书表填写约束

- “反馈质量（作业质量）”列下拉只有 `高质量`、`合格`、`不合格` 三个选项，不能填写 `红线`。
- 命中反馈质量红线或脏数据标签时，“反馈质量（作业质量）”填 `不合格`；具体类型写到“红线问题”列和逐模型平台质检的“脏数据标签”中，例如 `虚假反馈`、`trace和反馈结果明显不一致`、`完全敷衍`。
- 题目红线仍按任务质量口径处理；不要把题目红线和模型反馈红线混写到模型反馈质量列。

## 具体标签与判定依据

| 原标签 | 评估对象（纵轴） | 粒度（横轴） | 判定依据 |
| --- | --- | --- | --- |
| API 请求超时 / 轨迹大量 error | 平台 & 模型表现 | L1 | - API 超时：`status_code != 200`，且用户理由提「卡 / 超时 / 掉线 / 请求失败」，且效率维度打低分。<br>- 结构化字段异常：`ttft / tpot / input_tokens / output_tokens = null`。<br>- 排除项：`status_code = 200` 的红色记录是非流式输出，不算异常。<br>- 排除项：只看结构化字段，不把 message 文本 / tool result 当 API 异常证据。 |
| OpenClaw / Hermes 框架问题 | Harness 表现 | L1 | - 场景一（trace 完整）：轨迹有完整交付内容，但用户前端没收到，反馈「没完成 / 不完整 / 卡住」。<br>- 场景二（trace 不完整）：用户连续多条 user message，却无对应 assistant 回复与工具调用。<br>- 用户侧证据 + 轨迹侧证据缺一不可。<br>- 排除项：模型自己死循环 / 工具调用失败不会恢复 = 模型能力问题，不打此标签。 |
| 用户切换模型错误 | 平台 & 模型表现 | L1 | - 模型切换污染：模型自称身份 ≠ 接入点，且前段轨迹与他模型雷同（未清 workspace / 未 `/new`）。 |
| AI 打分 / AI 评价 | 反馈质量 | L1 & L2 | - AI 打分口癖：图标、百分制 / 小数制、「作为 AI」、过度 markdown、大量百分号。<br>- 轨迹含模型自评 / prompt 内置打分指令 / 产物里有 AI 打分文件。 |
| 敷衍恶意打分 | 反馈质量 | L1 | - 打分理由为空，或极短、无有效评判依据（极端分只配「还行」「不错」）。<br>- 同一维度评分标准前后不一（同项先给 3 分又给 6 分）。<br>- 不同评价板块结论相悖（综合说效率差，效率维度却说优异）。<br>- 非关联维度连带扣分（仅因响应慢，就给产物质量 / 综合打低分）。<br>- 评分与实际产物明显不符。 |
| 敷衍恶意打分 | 反馈质量 | L2 | - 多模型打分理由高度雷同 / 复制粘贴，未针对各模型独立评价。<br>- 未测完规定的全部模型就提交分数。<br>- 各模型分数完全一致，但实际表现明显有差异。 |
| 敷衍恶意打分 | 反馈质量 | L1 | 1. 虚假反馈：标注人明显编造评价内容，打分、备注或截图存在伪造行为（如截图与题目无关、备注内容抄袭或凭空捏造等）。<br>2. trace 和反馈结果明显不一致：模型的实际执行轨迹（trace）与标注人给出的打分和评价存在根本性矛盾（如 trace 显示代码完全无法运行，但标注人给了高分；或 trace 显示功能完整实现，标注人却判为不可用）。 |
| 题目红线（prompt 简单 / VLM 错配） | 题目质量 | L2 | - prompt 过于简单（如「你好」「写个 hello world」）。<br>- prompt 过于模糊，无明确目标 / 约束 / 验收标准（如「帮我做个东西」）。<br>- 纯「题库题」（数学题、LeetCode），脱离真实场景、无测试价值。<br>- VLM 错配：纯文本模型却要求输入 / 输出图片、音频、视频。<br>- 纯生图类任务：任务只要求生成图片，文本 LLM 天然无法完成。<br>- 全部模型工具调用轮次 < 10，未覆盖工具能力考察。<br>- 同一任务给各模型的 prompt 不一致，起点不公平。<br><br>补充红线：<br>1. 毫无意义的题目：题目内容空洞、随意拼凑、明显敷衍，不具备任何 coding 场景测试价值。<br>2. 非代码题：题目内容与代码 / 编程无关（如纯文本写作、问答题、设计题等）。<br>3. 题目不合理：需求本身存在逻辑矛盾，或无法实现，需求描述混乱或存在矛盾，导致无法正常评测。<br>4. 非本人场景：从 Openbenchmark 上找的评测题目。<br>5. 静态展示性页面：用网页生成 PPT、旅游攻略等。 |
| 低质量任务（非脏数据标签） | 题目质量 | L2 | - 4 模型综合分差 ≤ 1 且均分 >= 9，任务无法测出模型能力差异。<br>- 低价值任务。 |
